# DiskRescue Pro — First Version Preview

## What this version does

This is an early Windows x64 command-line preview for inspecting **regular disk-image files**. It opens the selected image read-only and emits a JSON report containing:

- Image length and selected logical sector size
- MBR signature, protective-GPT indicator, primary partition entries, and diagnostics
- GPT primary and backup header validity, partition entries, CRC validation results, and copy-consistency diagnostics

The preview supports 512-byte logical sectors by default. Supply `--sector-size 4096` for a 4Kn image.

## What it does not do

- It does not enumerate or open physical disks or volumes.
- It does not scan a damaged physical drive.
- It does not locate lost partitions yet.
- It does not parse NTFS, FAT32, or exFAT file systems.
- It does not list or recover files.
- It does not repair, initialize, format, repartition, or write to any source.

**Do not point this preview at a physical-device path. Do not experiment on the only copy of important data.** If a disk is clicking, repeatedly disconnecting, overheating, or returning repeated I/O errors, stop using it and consider professional recovery.

## Run from source

Install the .NET 10 SDK, clone the repository, then run:

```powershell
dotnet run --project src/DiskRescue.Cli -- inspect "C:\Images\sample.img"
```

For a 4Kn image:

```powershell
dotnet run --project src/DiskRescue.Cli -- inspect "C:\Images\sample-4kn.img" --sector-size 4096
```

The report is written to standard output as JSON. Redirect it to a separate report file if needed:

```powershell
dotnet run --project src/DiskRescue.Cli -- inspect "C:\Images\sample.img" > inspection-report.json
```

## Downloadable preview

The Windows CI workflow publishes a self-contained Windows x64 CLI preview as the GitHub Actions artifact named `DiskRescue-Pro-win-x64-preview`. Download and extract that artifact from a successful workflow run, then run:

```powershell
.\DiskRescue.Cli.exe inspect "C:\Images\sample.img"
```

Treat all findings as inspection evidence, not a guarantee that data can be recovered. Parser support is still limited to the documented MBR/GPT structures and synthetic-image validation.
